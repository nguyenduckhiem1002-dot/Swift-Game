# UI image generation prompts

The source images in this folder are preserved as generated. `Scripts/export_ui.swift` trims each cell inside the documented atlas grid, downsamples with nearest-neighbor sampling, and writes the runtime PNGs to `SwordDuel/Resources/Assets/UI/`. Pressed, disabled, cooldown, banner, and ultimate pulse states are exported or composed by that script where noted.

## Export notes

- The generated masters have transparent alpha. The user-provided magenta-background instruction was not used for these final exports.
- All menu labels and FIGHT / K.O. text are drawn by SpriteKit so they remain editable and readable.
- The four ULT pulse frames and eight cooldown wipe frames are arranged horizontally in their runtime strips. The cooldown strip is generated deterministically by the export script.
- Runtime dimensions, frame counts and states are listed in the UI assets table in the root `README.md`.
